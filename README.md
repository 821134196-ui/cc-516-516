# 🍃 阳光果园采摘券系统（演示版）

按作物 × 园区发售采摘券，覆盖「游客选时段预约 → 入口核销入园 → 离园称重结算 →
异常退改 / 离园补扣」全流程。仅依赖 Python 3.11 标准库；SQLite 存券与流水，
电子秤与支付均为**模拟适配器**，演示图片为本地 SVG。

## 一条命令启动

```bash
./run.sh             # 自动建库 + 播种演示数据 + 启动
./run.sh --reset     # 清库重建（推荐每次演示前）
PORT=8123 ./run.sh   # 换端口
```

打开 <http://127.0.0.1:8000>：

| 入口 | 地址 | 用途 |
| --- | --- | --- |
| 游客端 | `/` | 采摘日历（可约日期 + 剩余名额优先）、购票、券订单、转赠、退改 |
| 现场端 | `/onsite` | 大号券码核验、两入口切换、大号重量读数、称重结算 |
| 园区图 | `/map` | 四区平面图，绿色实线=可采边界，黄色虚线=临停边界，蓝色=雨天全园 |
| 管理端 | `/admin` | 停采发布/解除、受影响预约逐条退改、离园补扣、电子秤/支付模拟器 |

## 内置演示样例（相对启动当天）

- **今天**：`FARM-T10001~T10004`（四个时段各一张）、`FARM-S10001~S10003`
  （梨/葡萄/桃，S10003 含 1 名儿童）可直接核销；
  `FARM-IN0001` 已在园内（重放被拒）、`FARM-DONE01` 已结算锁定、
  `FARM-DEBT01` 现场扣款失败挂账（管理端可补扣）。
- **后天（雨天停园样例）**：全园停采，`FARM-R10001~R10006` 六张受影响预约，
  券订单页与管理端均提供免费改期 / 全额退款。
- **第四天**：B 区「果实未熟」临停，`FARM-U10001~U10002` 受影响。
- `FARM-IDLE01` 未预约、`FARM-GIFT01` 已转赠（订单页可查转赠留痕）。

推荐演示路径：现场端核销 `FARM-T10001` → 管理端设秤 5.2kg → 现场端称重
（3kg 免费，2.2kg × ¥16 = ¥35.20）→ 再扫该券被拒（重放/结果锁定）→
管理端「模拟断连」后称重得到断连错误且无记录 → 「下一笔支付失败」演练
扣款失败挂账 → 管理端离园补扣。

## 业务规则落点

- **雨天停园 / 果实未熟**：`zone_status`（全园行 `zone_code IS NULL`），
  日历、园区图、核销、预约/改期四处联动拦截。
- **券转赠**：未使用券可改持有人，原持有人写入 `gifted_from` 并留审计流水。
- **儿童免费重量**：免费额度 = 券基础重量 + 儿童数 × 0.5kg，超额才计费。
- **电子秤断连**：称重只接受秤适配器读数；断连直接报错、不落任何记录，
  检票员没有任何录入/修改重量的入口（`weighings.locked=1`）。
- **离园后补扣款**：现场扣款失败不拦离场，转 `debts` 挂账，管理端重试
  MockPayment，成功后补记 `kind='arrears'` 流水。
- **核销与改期互斥 / 不可重复入园**：所有状态写操作走 `BEGIN IMMEDIATE`
  串行事务 + 票状态机；两入口并发扫同一张券恰好一次成功。
- **临时停采退改**：管理端按停采范围列出受影响预约，逐条改期或全额退。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

17 个用例，覆盖任务要求的四类核心场景（另含转赠、断连、欠账）：

- `TestTicketReplay`：同口/跨入口重放拒绝、称重结果锁定、无预约不可核销；
- `TestWeighingBilling`：基础/儿童免费重量、超额计费、支付失败挂账与补扣、
  断连不产生记录；
- `TestClosureReschedule`：雨天拦截、改期后核销、区级停采隔离、全额退款、解除恢复；
- `TestConcurrentEntry`：两线程屏障并发核销仅 1 次入园；核销与改期不会同时成功。

## 代码结构

```
app/
  config.py      配色、时段、容量、儿童免重、单价等常量
  db.py          SQLite schema + BEGIN IMMEDIATE 事务
  clock.py       可注入时钟（测试固定时间）
  adapters.py    MockScale（读数/断连）、MockPayment（扣款/退款/失败注入）
  catalog.py     作物/园区/票种/日历与剩余名额查询
  tickets.py     购票、预约、改期、转赠、退款
  closures.py    停采发布/解除、受影响预约、退改处理
  operations.py  入口核销（防重放）、称重结算、欠账补扣
  views.py       全部页面渲染（白/果园绿/金黄）
  server.py      ThreadingHTTPServer 路由与权限边界
  seed.py        演示数据（含雨天停园样例）
static/          app.js + 本地 SVG 演示图片
tests/           领域层并发与规则测试
run.sh           一条命令启动
```
